# Física Geral III — Avaliação e gabarito interativo

Avaliação de Eletromagnetismo (IFES — Campus Vitória) com gabarito em Streamlit:
Biot–Savart, Faraday, indutância mútua, RLC série e alto-falante.

Todos os arquivos ficam **na mesma pasta** (sem subpastas). Arquivo principal: `app.py`.

```bash
pip install -r requirements.txt
streamlit run app.py
```

Publicação: share.streamlit.io → Create app → repositório, branch `main`, arquivo `app.py`.
